# 🦝 酒馆小狸 Live

坐在第四面墙外陪你玩卡的人。MCP 版小狸（tavern-tanuki）是给 agent 用的后台小狸，这个是现场版：一个酒馆助手脚本，悬浮球→小窗，窗里坐着一个陪玩人格，每回合正文出来后它看一眼说两句。

## 装法
酒馆助手 → 脚本库 → 导入 → 选 `tanuki_live_online.json`（在线版，本体从云端拉，作者发版你不用重导）→ 装到**全局**（它本来就是什么卡都能用）。QR 栏会多一个「🦝 小狸」按钮，右下角有悬浮球。

## 它能干什么
- **19 个内置人格**，一只小狸换道具：嗑学家🫧（默认）/ Akuma💅 / 编剧🎬 / 攻略党📖 / 阴谋论侦探🔍 / 路过的妈🧓 / 特朗噗🇺🇸 / 动物世界旁白🦁 / 相亲角大妈🧺 / 催更猫头鹰🦉 / 反派智囊🐍
- **8 位外语老师**（英🇬🇧 德🇩🇪 法🇫🇷 日🇯🇵 韩🇰🇷 西🇪🇸 意🇮🇹 俄🇷🇺）：每轮从正文里揪一句，告诉你母语者在这种场合真的会怎么说——先外语后中文讲解，一次只教一个点。好笑，但真能学
- **导入任何 NPC**：设置页填名字 + 一段描述（可直接贴世界书条目），把 ta 请到第四面墙外坐你旁边
- **它看得到**：角色卡描述、你的 persona、预设名、模型、层数、最近几层正文、聊天变量（MVU `stat_data` 优先）、绑定的世界书、本轮触发了哪些条目
- **它说的话不进主线**。它出的主意会单独一行 💡，旁边有「采纳」——点了才以一次性注入塞进下一轮，用完自动撤
- **自动 / 手动**：⚡ 开着就每 N 层自己说；关了就点 💬 或直接在输入框问它
- **球上冒气泡**：小窗收着时它的话直接冒在悬浮球顶上，几秒后自己缩回；点气泡展开小窗。设置里可关
- **连发**：它想多说时拆成几条消息连着发，像真人聊天
- **小窗可拖**：抓顶栏拖，松手记位置；设置里有「回默认位置」
- **不漏层**：它还在说时新正文出来了会排队补说
- 对话记录按 聊天 × 人格 分开存：换人格只看到它自己的对话，切回去旧的还在
- **API**：一次开口 = 一次独立生成（默认用你酒馆当前的连接，不走你的预设）。设置里可以单独填一套便宜的 OpenAI 兼容 API，Key 只存浏览器本地

## 文件（开发用）
- `tanuki_live.js` — 唯一真本，改这个
- `build_public.js` — 剥掉私有段落出公开版 `tanuki_live.public.js`（发版.ps1 自动跑）
- `build_loader.js` — 出在线版 JSON（脚本库里只放加载器）
- `酒馆助手脚本-🦝酒馆小狸Live.json` — 全量离线版（改完 js 重新跑下面的命令同步）
- `发版.ps1 "一句话"` — 一条龙：校验 → 剥公开版 → 拷进发布仓库 → push → 切指针

```bash
# 同步全量离线版 JSON（在本目录）
python -c "import json;src=open('tanuki_live.js',encoding='utf-8').read();d=json.load(open('酒馆助手脚本-🦝酒馆小狸Live.json',encoding='utf-8'));d['content']=src;json.dump(d,open('酒馆助手脚本-🦝酒馆小狸Live.json','w',encoding='utf-8'),ensure_ascii=False,indent=1)"
```
