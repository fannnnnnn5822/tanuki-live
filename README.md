# 🦝 酒馆小狸 Live

坐在第四面墙外陪你玩卡的人。MCP 版小狸（tavern-tanuki）是给 agent 用的后台小狸，这个是现场版：一个酒馆助手脚本，悬浮球→小窗，窗里坐着一个陪玩人格，每回合正文出来后它看一眼说两句。

## 文件
- `tanuki_live.js` — 唯一真本，改这个
- `酒馆助手脚本-🦝酒馆小狸Live.json` — 导入酒馆助手用的包（改完 js 重新跑下面的命令生成）

```bash
# 重新打包（在本目录）
python -c "import json,uuid;src=open('tanuki_live.js',encoding='utf-8').read();d=json.load(open('酒馆助手脚本-🦝酒馆小狸Live.json',encoding='utf-8'));d['content']=src;json.dump(d,open('酒馆助手脚本-🦝酒馆小狸Live.json','w',encoding='utf-8'),ensure_ascii=False,indent=1)"
```

## 装法
酒馆助手 → 脚本库 → 导入 → 选 JSON → 装到**全局**（它本来就是什么卡都能用）。QR 栏会多一个「🦝 小狸」按钮，右下角有悬浮球。

## 它能干什么（v0.1.0）
- **12 个内置人格**（v0.1.10：红笔编辑移出公开版；编剧升级为 HBO 级 showrunner，盯剧情也把控走向）
- **8 个原装人格**：Akuma💅 / lundiiszy👽（绿星人，v0.1.8 Fan 的声线已进）/ 编剧🎬（占位，现在是剧本医生，等 Fan 的 drama 编剧）/ 嗑学家🫧 / 攻略党📖 / 阴谋论侦探🔍 / 红笔编辑🖊️ / 路过的妈🧓
- **导入任何 NPC**：设置页填名字 + 一段描述（可直接贴世界书条目），灵魂锚定轻量版把 ta 挪到第四面墙外
- **它看得到**：角色卡描述、你的 persona、预设名、模型、层数、最近 6 层正文、聊天变量（MVU `stat_data` 优先）、绑定的世界书、本轮触发了哪些条目（`WORLD_INFO_ACTIVATED`）
- **它说的话不进主线**。它出的主意会单独一行 💡，旁边有「采纳」——点了才 `injectPrompts({once:true})` 塞进下一轮，用完自动撤
- **自动 / 手动**：⚡ 开着就每 N 层自己说；关了就点 💬 或直接在输入框问它
- **球上冒气泡**（v0.1.4，学自桌宠「戳戳」）：小窗收着时它的话直接冒在悬浮球顶上，按字数停几秒自己缩回；点气泡展开小窗。设置里可关，默认开
- **连发**（v0.1.10）：它想多说时按空行拆成 1～3 条消息连着发，像真人聊天；💡 建议跟着前一条走
- **小窗可拖**（v0.1.11）：抓顶栏拖，松手记位置；设置里有「回默认位置」
- **连发**（v0.1.10）：它想多说时按空行拆成 1～3 条消息连着发，像真人聊天；💡 建议跟着前一条走
- 对话记录按 聊天 × 人格 分开存（聊天变量 `tanuki_live.logs[人格id]`，每份上限 40 条）：换人格只看到、也只喂给模型它自己的对话，切回去旧的还在（v0.1.9，旧单份 `log` 自动迁移）
- 一次开口 = 一次 `generateRaw`（用当前 API 和模型，不走玩家预设）

## 结构
悬浮面板骨架（`.claude/skills/write-card/scripts/悬浮面板骨架.js`）+ generateRaw 独立生成 + injectPrompts once 回灌。cleanup 收：DOM / 事件 / 定时器 / 注入。
